# 🏛️ Основні принципи та маніфест архітектури: JARVIS Core

## 1. Місія та сфера застосування системи
JARVIS Core — це хмарна B2B платформа автономної інфраструктури (AIOps) та самовідновлюваного коду, розроблена для екосистеми Microsoft Azure. Система створена для:
- Оркестрації високонавантажених асинхронних мікросервісів та забезпечення безперервної операційної стійкості.
- Автономного виявлення "програмного тертя", ізоляції несправностей та синтезу безпечних патчів на льоту за допомогою моделей Azure OpenAI (GPT-4o).
- Гарантування найвищого рівня Enterprise-безпеки через концепцію нульової довіри (Zero-Trust) та детерміновану інтроспекцію коду.

## 2. 24 Аксіоми безпеки та філософія виконання
- **Точність рівня AST (Abstract Syntax Tree):** Ядро використовує синтаксичну інтроспекцію для хірургічної точкової заміни логіки замість монолітного перезапису файлів, зберігаючи цілісність топології.
- **Щит Аксіом (CodingAxiomsShield):** Кожна згенерована ШІ мутація проходить жорстку статичну перевірку за 24 інженерними аксіомами (сувора заборона блокуючого I/O в async-циклах, недопустимість порожніх винятків `except: pass`, контроль витоків пам'яті).
- **Збереження контрактів та AtomicRollback:** Будь-яке гаряче оновлення (hot-reload) суворо зберігає функціональні сигнатури типів. У разі виникнення середовищних аномалій, система миттєво активує ізольований відкат на попередній стабільний снапшот.
- **Сувора гігієна пам'яті:** Системні журнали обмежені жорсткими ковзними буферами (ліміт 1 МБ) без генерації нестисненого сміття. Довгостроковий стан зберігається виключно у транзакційних базах (SQLite WAL) та векторних сховищах (ChromaDB).

## 3. Контур Пропріоцепції та Когнітивна Телеметрія
- **Пропріоцептивний моніторинг (VitalMonitor):** Проактивна телеметрія безперервно вимірює затримки на IPC-шині подій (з вимогою < 250 мс) та апаратний опір (CPU/RAM), автоматично ветуючи оновлення, що викликають асинхронне голодування (`Async Starvation`).
- **Кристалізація знань (DreamProcessor):** Під час станів очікування (idle), розрізнені телеметричні дані та помилки виконання консолідуються у векторні "Кристали Знань" за допомогою паралельного контуру Azure OpenAI (GPT-4.1-mini).
- **Делегований шлюз телеметрії:** Ядро безпечно передає телеметрію в реальному часі на голографічний веб-інтерфейс (WarRoom) через захищені канали FastAPI та WebSockets.

## 4. Заходи кібербезпеки та Zero-Trust (AegisCore)
- **Ізоляція облікових даних:** Усі токени автентифікації, ключі Azure IAM та криптографічні секрети суворо ізолюються під час завантаження ядра і залишаються на 100% недоступними для аналітичних пісочниць та згенерованих воркерів.
- **Шестирівневий захист (AegisCore):** Вбудований щит включає `ProcessGuard` (моніторинг цілісності процесу), `RansomwareLock` (блокування доступу до SQLite WAL файлів), та `FileMonitor` (FIM-аудит файлової системи).
- **Виконання в пісочниці (TestForge):** Згенеровані ШІ модифікації та тести виконуються виключно в ефемерних ізольованих середовищах перед будь-якою спробою гарячого перевантаження.
- **Human-in-the-Loop (WarRoom):** Критичні оновлення архітектури з високим індексом складності генерують візуальний diff для ручного підтвердження Архітектором через термінал командного центру.

## 5. Інженерні стандарти та якість коду
- **Сувора безпека типів:** Усі вузли використовують суворе статичне типізування (Python 3.11+) та явну обробку винятків на всіх мережевих межах.
- **Гарантія нульового заповнювача (Zero-Placeholder Guarantee):** Код виробничого (production) рівня, згенерований платформою, ніколи не містить усічених реалізацій, коментарів типу `// TODO` або фіктивної логіки.
- **Динамічний розподіл ресурсів:** Бюджети обчислень контролюються модулем `QuotaWarden`, що гарантує резервування пулу Azure-токенів та процесорного часу для пріоритетних системних потоків.
